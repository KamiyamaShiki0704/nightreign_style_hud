# v0.3.2 - Elden Ring 1.17.1 / Precision Aim

## English

- Updated both `nightreign_style_hud.dll` and standalone
  `nightreign_precision_aim.dll` for Worldwide ER 1.17.1 (EXE 2.7.1.0).
- Pinned fsrs to `3c8c1d7633a99309fb004c9f894ea10b7967d0e0`.
  Adds a separate 92-entry version table; five native addresses changed.
  Previously supported version mappings remain intact; new JP 2.7.1.x is unverified.
- Standalone aim keeps SpEffect `883100`, existing camera tuning and external
  `assets/Precision_Reticle1..3.png` customization. Both packages now share
  this release page. Preserve customized PNGs when updating.
- Includes the post-v0.3.1 Revenant passive conversion and Scholar scan fixes.
  Diagnostic overlays/logging removed by those fixes remain disabled.
- Includes Undertaker normal/enhanced buffs `880920` / `880921`, pre-hit
  auto-dodge request `880922`, and Atk direction markers `880930..880934`.
  Import the supplied SpEffect rows and select animations in your HKS.
  Player-relative received-direction markers `880935..880938` are NOT included
  in this compatibility release; they are a separate development task.
- Both DLLs use x64 static MSVC CRT. Main HUD tests: 45/45; standalone
  tests: 3/3; locked offline release builds and PE/archive checks passed.
  Game startup, role behavior and standalone/coexistence checks still require
  in-game acceptance on 1.17.1; builds are not a guarantee of every runtime path.

### Packages

- `nightreign_style_hud_v0.3.2.zip`: main DLL, README, licenses and SpEffect CSV.
- `nightreign_precision_aim_v0.3.2.zip`: standalone DLL, README, licenses and assets.
- Bare DLLs and `SHA256SUMS.txt` are also provided.
- When the full HUD is loaded, the standalone DLL defers to its existing
  `883100` implementation instead of installing a duplicate render/task hook.
  Validate standalone private assets with the full HUD disabled.
