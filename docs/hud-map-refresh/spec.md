# HUD 可见性与隐士刷新清理

用户于 2026-09-24 报告并明确预期：HUD 只在传送加载界面出现、正常游戏消失是错误；隐士元素槽位应在地图刷新后清空。
本修复恢复这两项行为。作用域为 nightreign_style_hud，保留之前送葬者和复仇者改动。

- SPEC-HMR-01：当玩家正常在地图内活动且原生界面允许显示时，应显示角色 HUD，不受复仇者清理队列是否有会话的影响。
- SPEC-HMR-02：当传送加载画面持续显示时，应一直隐藏角色 HUD；加载时间超过原有 1.5 秒保护期也不能露出。加载结束后恢复显示。
- SPEC-HMR-03：当地图刷新时，应清空隐士三个元素槽、已准备的混合魔法与旧目标元素缓存；再次进入可操作地图时应清掉对应旧输出，允许重新吸收元素。
- SPEC-HMR-04：当仅打开普通菜单且没有地图刷新时，不应清空元素槽。复仇者原有家族 HP 记忆继续保留。

验收：P01 正常游戏显示；P02 传送加载超过 1.5 秒仍隐藏、完成后恢复；P03 吸收 1–3 个元素后刷新，三个槽与就绪魔法清空，重新吸收可用；P04 普通菜单开关保留槽位。
自动回归覆盖可见性条件与真实地图刷新方法；读取本机游戏/原生代码核对加载字段。游戏内画面与交互由用户最终验收。
不改概率、伤害、充能规则、HKS 或参数；不宣称旧版/联机全覆盖。
